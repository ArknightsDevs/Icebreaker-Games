# 页面

### 页面-1 画面设置

画面的开销由玩家选择（引擎 ADR 0059），页面左侧的「画面」标签打开设置，选择立即生效，并保存在本机：

| 设置 | 选项 | 默认 |
|---|---|---|
| 帧率上限 | 跟随屏幕、144、120、60、30 | 跟随屏幕 |
| 清晰度 | 100%、75%、50%（画布像素比相对设备像素比，引擎 渲染-15） | 100% |
| 攻击特效 | 开、关（引擎 渲染-15） | 开 |
| 显示帧率 | 关、开（左下角显示最近一秒画了多少帧） | 关 |
| 音乐 | 100%、50%、关（页面-4） | 100% |
| 音效 | 100%、50%、关（页面-4） | 100% |
| 语音 | 100%、50%、关（页面-4） | 100% |
| 配音 | 默认，以及素材的语音里有的中文-普通话、日语、英语、韩语（页面-4）；素材里没有语音时不显示这一项 | 默认 |

- **帧率上限**：有上限时，屏幕的每次刷新只在距上一次绘制的时间槽满一个间隔（1000 ÷ 上限 毫秒）时绘制，早到 1.5 毫秒以内也算到了；间隔两倍以上没有绘制时，时间槽从这一帧重新开始。
- **保存**：本机存不了时（隐私模式等），选择只在这一页有效；存的内容不完整或有误时，那一项用默认值。
- 设置只影响画面，战斗照常每秒 30 帧（引擎 时间-1）。

- 来源：设计决定，见引擎 [ADR 0059](https://github.com/Cloudnyco/Arknights-Universal-Engine/blob/main/docs/adr/0059-player-chosen-performance.md)

### 页面-2 本地存档与 box 录入

房间页下方是玩家的干员 box、常规队和比赛风格（房间-3），连同玩家的名字存在本机浏览器里：

- **录入**：输入干员名加入 box，起始为满练度：最高的精英化与等级、已开放技能的最高等级、潜能 1、信赖 100%、模组未解锁。之后可以在这名干员的上限之内修改精英化、等级、潜能（1 至 1 + 潜能提升次数）、信赖（0–200%）、各技能等级和各模组阶段。
- **上限**：技能随精英化开放；技能等级在精英 0 最高 4 级，精英 1 最高 7 级，精英 2 可专精到 3 级（技能自己的等级数更少时以它为准）。模组在精英化和等级达到它的要求后才能升到 1–3 级。改动精英化或等级后，超出上限的项降到上限。
- **常规队**：box 里的干员可以放进高顺位或低顺位，或移出常规队；某一边满了时不能再放（房间-3 的人数）。从 box 删除的干员也离开常规队。「随机填满常规队」随机挑选还不在常规队里的六星干员，以满练度补到高顺位 10 名、合计 20 名。
- **保存**：每次改动立即保存在本机。存不了时（隐私模式等），改动只在这一页有效，页面会提示。读到的存档不完整或有误时，原文另存一份，换成空存档。
- **比赛风格**：五种风格各一个按钮，选中的风格下面写着它的增益、代价和携带物的效果。没有记下风格的存档按基础处理。
- **导出与导入**：存档可以导出为一段文本，再从文本导入；不是合格存档的文本不会导入，页面说明原因。

- 来源：设计决定（计划 6.2，问答 7、8：存档默认在本地，box 手动录入）；技能等级的开放条件取自游戏数据 `character_table.json` 的 `allSkillLvlup[].unlockCond`（2–4 级 PHASE_0、5–7 级 PHASE_1，全部 439 名干员相同）与 `skills[].levelUpCostCond[].unlockCond`（专精都要 PHASE_2）；技能与模组的开放条件、等级上限、潜能提升次数取自引擎的干员训练数据（引擎 干员-1）

### 页面-3 局域网打开的页面

经局域网地址（如 `http://192.168.1.2:8700/`）打开的页面不是安全上下文，只能用不需要安全上下文的浏览器功能：会话密钥用 `crypto.getRandomValues` 生成，不用 `crypto.randomUUID`；复制邀请文字由玩家自己选中复制，不用剪贴板接口。

- 来源：设计决定；安全上下文的限制见 [MDN「Secure contexts」](https://developer.mozilla.org/en-US/docs/Web/Security/Secure_Contexts/features_restricted_to_secure_contexts)（`crypto.randomUUID`、`navigator.clipboard` 只在安全上下文可用）

### 页面-4 声音

对局页按引擎的音频规则出声（引擎 音频-1…6）：

- 素材里有音频索引（`audio/index.json`）时才有声音；没有时整页静音，对局照常进行。
- 浏览器要等玩家第一次点按或按键后才让页面出声，所以在那之前听不到声音。
- 每帧的表现事件按 音频-2 播放音效；战斗从第 0 帧开始时播放关卡的音乐（音频-3），战斗结束时淡出。
- 服务器的控制消息（引擎 同步-7、同步-8）里，协作者申请暂停时播 `battle.ON_COOPERATE_PAUSE_CONFIRM`；协作者打开二倍速、而自己还没打开时播 `battle.ON_COOPERATE_SPEED_REQUEST`。
- 素材里有语音索引（`voice/index.json`）时干员说话（引擎 音频-4…6）：
  - 拿到这一局的内容后，先加载自己座位的干员按当前配音的全部台词。
  - 每帧的表现事件按 音频-5 说话：部署、部署后第一次攻击敌人、技能开启。
  - 页面在战斗开始前就打开时，战斗从第 0 帧开始的同时，由自己编队里第一名有台词的干员说「行动出发」。战斗开始后才打开（重连）的页面不说。
  - 原样式界面里，按下一张能用的手牌，或点开场上自己的干员的菜单，就是选中这名干员，说「选中干员」。
- 音乐、音效、语音的音量由画面设置里的「音乐」「音效」「语音」决定（页面-1）。
- 配音由画面设置里的「配音」决定：「默认」是每名干员自己的默认配音，选了语言而这名干员没有时也用默认配音（引擎 音频-4）。

- 来源：设计决定（引擎 ADR 0024、ADR 0061，规划问答 Q69）；配音的选项和名字：数据 charword_table.json `voiceLangTypeDict`；语音的时机为推断，同引擎 INF-0172；浏览器的自动播放限制见 [MDN「Autoplay guide for media and Web Audio APIs」](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)；协作者申请时的提示音为推断，同引擎 INF-0169

### 页面-5 房间页的图标和音乐

素材里有房间页的图集（`ui/room/index.json`）时，房间页用活动的图标；没有时只显示文字，其余照常：

- **比赛风格**：每种风格的图标按活动表里它的图标编号取（基础 `buff_icon_basic`、驻场 `buff_icon_anchoring`、游走 `buff_icon_roaming`、攻坚 `buff_icon_offensive`、支援 `buff_icon_supportive`），颜色用它的主题色。
  - 选风格的按钮带小图标（`_tiny`）。
  - 选中的风格在说明旁边显示完整的图标。
  - 项目确认时自己的风格，组建上场阵容时双方的风格，前面都带小图标。
- **项目的模式**：项目说明前显示模式名「常规项目」，用活动表里模式的颜色，前面是这种模式的图标。

素材的音频索引里有音乐库 `sys.ON_MULTIV3_LOADED`（「促融共竞」主界面的《罗德行进曲》）时，房间页播放它：

- 先播前奏，前奏结束时接上循环段，一直循环。音量是这个库的音量乘以玩家的音乐音量。
- 浏览器要等玩家第一次点按或按键后才让页面出声，所以音乐从那时开始。
- 页面右上角的「音乐」按钮在 100%、50%、关 之间切换。它就是画面设置里的「音乐」（页面-1），两个页面共用这一项。
- 比赛开始、页面转到对局页时，音乐按库的交叉淡化秒数淡出，然后才转页面。

- 来源：数据：activity_table.json `MULTIPLAY_V3/act1multi` 的 `squadEffectList[]`（iconId、themeColor）、`mapModeDataDict.NORMAL`（name「常规项目」、color d2284b）；audio_data.json `bgmBanks` 的 `sys.ON_MULTIV3_LOADED`（m_sys_act1multi_intro、m_sys_act1multi_loop、volume 1、crossfade 1）；[PRTS「音乐鉴赏/游戏内音乐一览」oldid=440958](https://prts.wiki/index.php?title=%E9%9F%B3%E4%B9%90%E9%89%B4%E8%B5%8F/%E6%B8%B8%E6%88%8F%E5%86%85%E9%9F%B3%E4%B9%90%E4%B8%80%E8%A7%88&oldid=440958)：sys_act1multi 为「促融共竞#1 OST - 罗德行进曲」「「促融共竞」主界面BGM」；图标取自素材的图集；模式图标的对应、各种图标用在哪里为推断 INF-0005；音乐在房间页播放、离开时淡出再转页面为推断 INF-0006
