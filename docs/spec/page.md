# 页面

### 页面-1 画面设置

画面的开销由玩家选择（引擎 ADR 0059），页面左侧的「画面」标签打开设置，选择立即生效，并保存在本机：

| 设置 | 选项 | 默认 |
|---|---|---|
| 帧率上限 | 跟随屏幕、144、120、60、30 | 跟随屏幕 |
| 清晰度 | 100%、75%、50%（画布像素比相对设备像素比，引擎 渲染-15） | 100% |
| 攻击特效 | 开、关（引擎 渲染-15） | 开 |
| 显示帧率 | 关、开（左下角显示最近一秒画了多少帧） | 关 |

- **帧率上限**：有上限时，屏幕的每次刷新只在距上一次绘制的时间槽满一个间隔（1000 ÷ 上限 毫秒）时绘制，早到 1.5 毫秒以内也算到了；间隔两倍以上没有绘制时，时间槽从这一帧重新开始。
- **保存**：本机存不了时（隐私模式等），选择只在这一页有效；存的内容不完整或有误时，那一项用默认值。
- 设置只影响画面，战斗照常每秒 30 帧（引擎 时间-1）。

- 来源：设计决定，见引擎 [ADR 0059](https://github.com/Cloudnyco/Arknights-Universal-Engine/blob/main/docs/adr/0059-player-chosen-performance.md)

### 页面-2 本地存档与 box 录入

房间页下方是玩家的干员 box 和常规队（房间-3），连同玩家的名字存在本机浏览器里：

- **录入**：输入干员名加入 box，起始为满练度：最高的精英化与等级、已开放技能的最高等级、潜能 1、信赖 100%、模组未解锁。之后可以在这名干员的上限之内修改精英化、等级、潜能（1 至 1 + 潜能提升次数）、信赖（0–200%）、各技能等级和各模组阶段。
- **上限**：技能随精英化开放；技能等级在精英 0 最高 4 级，精英 1 最高 7 级，精英 2 可专精到 3 级（技能自己的等级数更少时以它为准）。模组在精英化和等级达到它的要求后才能升到 1–3 级。改动精英化或等级后，超出上限的项降到上限。
- **常规队**：box 里的干员可以放进高顺位或低顺位，或移出常规队；某一边满了时不能再放（房间-3 的人数）。从 box 删除的干员也离开常规队。「随机填满常规队」随机挑选还不在常规队里的六星干员，以满练度补到高顺位 10 名、合计 20 名。
- **保存**：每次改动立即保存在本机。存不了时（隐私模式等），改动只在这一页有效，页面会提示。读到的存档不完整或有误时，原文另存一份，换成空存档。
- **导出与导入**：存档可以导出为一段文本，再从文本导入；不是合格存档的文本不会导入，页面说明原因。

- 来源：设计决定（计划 6.2，问答 7、8：存档默认在本地，box 手动录入）；技能等级的开放条件取自游戏数据 `character_table.json` 的 `allSkillLvlup[].unlockCond`（2–4 级 PHASE_0、5–7 级 PHASE_1，全部 439 名干员相同）与 `skills[].levelUpCostCond[].unlockCond`（专精都要 PHASE_2）；技能与模组的开放条件、等级上限、潜能提升次数取自引擎的干员训练数据（引擎 干员-1）

### 页面-3 局域网打开的页面

经局域网地址（如 `http://192.168.1.2:8700/`）打开的页面不是安全上下文，只能用不需要安全上下文的浏览器功能：会话密钥用 `crypto.getRandomValues` 生成，不用 `crypto.randomUUID`；复制邀请文字由玩家自己选中复制，不用剪贴板接口。

- 来源：设计决定；安全上下文的限制见 [MDN「Secure contexts」](https://developer.mozilla.org/en-US/docs/Web/Security/Secure_Contexts/features_restricted_to_secure_contexts)（`crypto.randomUUID`、`navigator.clipboard` 只在安全上下文可用）
