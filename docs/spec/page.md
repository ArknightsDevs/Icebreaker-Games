# 页面

### 页面-1 画面设置

画面的开销由玩家选择（引擎 ADR 0059），页面左侧的「画面」标签打开设置，选择立即生效，并保存在本机：

| 设置 | 选项 | 默认 |
|---|---|---|
| 帧率上限 | 跟随屏幕、144、120、60、30 | 跟随屏幕 |
| 清晰度 | 100%、75%、50%（画布像素比相对设备像素比，引擎 渲染-15） | 100% |
| 攻击特效 | 开、关（引擎 渲染-15） | 开 |
| 显示帧率 | 关、开（左下角显示最近一秒画了多少帧） | 关 |

- **帧率上限**：有上限时，屏幕的每次刷新只在距上一次绘制的时间槽满一个间隔（1000 ÷ 上限 毫秒）时绘制，早到 1.5 毫秒以内也算到了；间隔两倍以上没有绘制时，时间槽从这一帧重新开始。
- **保存**：本机存不了时（隐私模式等），选择只在这一页有效；存的内容不完整或有误时，那一项用默认值。
- 设置只影响画面，战斗照常每秒 30 帧（引擎 时间-1）。

- 来源：设计决定，见引擎 [ADR 0059](https://github.com/Cloudnyco/Arknights-Universal-Engine/blob/main/docs/adr/0059-player-chosen-performance.md)
