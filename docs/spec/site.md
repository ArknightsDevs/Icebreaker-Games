# 站点

平台作为一个网站对外提供时的行为：挂在什么地址下、怎么经反向代理对外。局域网里直接打开服务器端口（页面-3）是这里的特例。

### 站点-1 挂在任意路径下

- 平台的页面在同一层：首页 `./`（房间页，或只有一局时的对局页）、对局页 `./play`、房间页 `./room`。页面用到的其余地址都在页面旁边：页面文件 `static/`、模块 `m/`、kit `k/`、素材 `assets/`，大厅与对局的 WebSocket `lobby`、`battle`。
- 页面里的每个地址都按页面自己的地址取相对路径，样式表里的（字体）按样式表的地址，不从站点根目录写起；WebSocket 的地址同样按页面的地址取，`http:` 的页面用 `ws:`，`https:` 的页面用 `wss:`。
- 服务器改写模块里的导入（裸模块名，以及 kit 对引擎模块的导入）时，写成相对于这个模块自己地址的路径。
- 所以平台可以直接挂在根目录（`https://ig.example/`），也可以挂在反向代理的一个子路径下（`https://example/icebreaker/`）：代理把这个前缀去掉后转给服务器（含 WebSocket 升级），服务器不需要知道前缀，前缀之外什么也不请求。

- 来源：设计决定：同一域名下已有别的游戏用了根路径的 `/lobby` 等地址（部署记录），平台要能和它们共用一个域名
